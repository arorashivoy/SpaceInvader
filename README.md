# SpaceInvader

**Archived and unfinished.** A Space Invaders attempt in Java with
[libGDX](https://libgdx.com), November 2022. Two days of commits.

What exists: a shooter that moves and fires, bullets with collision against four
static blocks, and a desktop launcher. **There are no aliens** — `assets/Alien.png` is
committed but nothing ever loads it, so there is no enemy, no wave, and no way to win
or lose. It is the scaffolding of the game, not the game.

Run with `./gradlew desktop:run`.
